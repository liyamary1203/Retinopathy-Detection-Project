🩺 Diabetic Retinopathy Detection Using Deep Learning

📌 Project Overview

Diabetic Retinopathy Detection is a deep learning-based project designed to identify diabetic retinopathy from retinal fundus images.

The project explores the use of image processing and deep learning techniques to classify retinal images and assist in the early identification of diabetic retinopathy.

This project was developed as a collaborative academic mini project by a team of four members, with the support of AI-assisted development tools.

🎯 Objectives

- Develop a deep learning-based approach for diabetic retinopathy detection.
- Process and analyse retinal fundus images.
- Train and evaluate an image classification model.
- Explore the application of AI in healthcare.
- Build an accessible application for interacting with the trained model.

🛠️ Technologies Used

- Programming Language: Python
- Deep Learning: TensorFlow / Keras
- Model Architecture: EfficientNetB0 (verify against the final implementation)
- Image Processing: OpenCV, Pillow
- Frontend: HTML, CSS
- Backend: Flask
- Development Environment: Visual Studio Code
- AI-Assisted Development: Google Antigravity and ChatGPT

🧠 Methodology

The project follows a deep learning-based image classification workflow:

1. Dataset Collection: Retinal fundus images are collected from the available datasets.
2. Preprocessing: Images are resized and prepared for model training.
3. Model Development: A deep learning model is used to learn relevant visual features from retinal images.
4. Model Training: The model is trained using the prepared image dataset.
5. Evaluation: Model performance is assessed using evaluation metrics.
6. Application Development: A web interface allows users to interact with the detection system.

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/liy amary1203/Retinopathy-Detection-Project.git

Remove the space in the username when entering the actual URL.

2. Navigate to the project directory

cd Retinopathy-Detection-Project/Retinopathy_Detection

3. Create a virtual environment

python -m venv venv

Activate it on Windows:

venv\Scripts\activate

4. Install dependencies

If the repository contains a "requirements.txt" file:

pip install -r requirements.txt

Otherwise, install the dependencies specified by the project source code.

5. Run the application

python app.py

Open the local URL displayed in the terminal in your web browser.
